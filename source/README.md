# 일러스트 소스 폴더

템플릿별 폴더에 넣어주세요. 새 템플릿은 폴더를 하나 더 만들면 됩니다.

- homeparty/ : 홈파티 포스터 (선물상자 연출)
- wine/ : 와인 파티 (커튼 & 건배 연출)

## 파일 형식 (좋은 순서)
1. SVG — 움직일 부분을 그룹/레이어로 나눠서 (예: ribbon, lid, glass-left)
2. 투명 배경 PNG — 움직일 부분마다 따로 한 장씩
3. Lottie(JSON) / Rive(.riv) — 이미 움직임이 있는 소스

## 같이 적어주면 좋은 것 (notes.md 한 파일)
- 파일 이름 → 무엇인지, 어떻게 움직였으면 하는지 한 줄씩
  예) ribbon.svg — 1,000원 연출에서 리본이 풀리듯 늘어지며 사라짐
- 출처와 라이선스 (Canva 요소라면 그 사실도)
